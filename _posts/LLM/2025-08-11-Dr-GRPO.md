# Analysis on Base Models
Analyzing the effect of RL training of R1-zero model
## Templates Construct Exploratory Base Policies
Qwen, Llama, DeepSeek base model 를 이용해 template 여부에 따라  answering format 으로 답하는지 sentence completion format 으로 답하는지 실험해본다. Format 을 따르는지 여부는 GPT-4o-mini 를 이용한다. 결과는 DeepSeek 의 base 모델이 template 을 사용하지 않았을 때 answering format 비율이 가장 낮았고 가장 pure한 base 모델임을 알 수 있다. 또, 3가지 base 모델 모두 기본 math accuracy를 0보다 큰 값을 가지고 있기 때문에 RL에 사용할 수 있다. Qwen base 모델이 accuracy 값이 가장 크기 때문에 RL 연구에 많이 이용된다. (기본 정확도가 있어서 reward signal을 얻을 수 있으니)

## Qwen-2.5 Models Unlock the Best Performance When Discarding Template
본 논문에 따르면 Qwen2.5 base 모델은 template 을 사용하지 않고도 answering format으로 대답하는 비율이 매우 높다. 심지어 Qwen template, 4-shot prompting, R1 template 등을 사용하는 것보다 단순히 question을 제시하는 것이 가장 정확도가 높았다. 이는 Qwen2.5 model이 question-answer pair 형태를 통해 pretraining을 했을 가능성이 높고 pure base 모델로 적절하지 않을 수도 있다.

## Aha Moment in Base Models
Aha Moment: self-reflection behavior (reasoning 과정에서 스스로 다시 생각해보는 모습을 보임) DeepSeek-Base 모델에서도 Aha moment 를 발견할 수 있었다. 이를 통해 Aha moment가 RL을 통해 새로 발견된 능력이 아니라, RL을 통해 강화 되었을 것으로 설명할 수 있다. 게다가 RL 이후에 self-reflection behavior가 자주 등장한 것은 맞으나 이 pattern이 accuracy로 바로 연결된 것은 아닌 것으로 보인다.

# Analysis on RL
## GRPO Leads to Biased Optimization
DeepSeek-R1-Zero 는 학습을 하는 동안 response length 가 계속 늘어나는 현상을 보이는데 이는 모델이 생각을 오래 해서 답변을 내는 것으로 생각할 수 있지만 본 논문에서는 GRPO objective에 존재하는 bias 때문이라고 설명하고 있다.

![](/assets/img/Dr.GRPO/grpo.webp)

- Response-level length bias: $\vert o_i\vert$ 로 나누는 것 때문에 bias 가 발생한다고 설명하고 있다. Positive advantage의 경우, shorter response에 더 큰 gradient signal => correct answer일수록 더 짧은 답을 선호하게 된다. 반대로 negative advantage의 경우, longer response일 수록 penalty를 덜 받게 되서 incorrect response일 수록 모델은 더 긴 정답을 선호하게 된다.
- Question-level difficulty bias: Advantage 를 계산할 때 deviation으로 나누는 것 때문에 bias가 발생한다고 설명하고 있다. 너무 쉽거나 너무 어려워서 reward가 0 혹은 1로 치중되는 경우 deviation이 낮아서 advatnage 값이 커져서 policy update에서 큰 weight을 가지게 된다. 즉, question-level로 정규화를 하다보니 question 난이도에 따라서 training signal이 달라지게 된다.

또, 기존에 PPO를 reproduce 하려고 한 open-source implementation에서도 response length로 loss를 normalize 했다:

```python
def masked_mean(tensor, mask, dim):
  return (tensor*mask).sum(axis=dim) / mask.sum(axis=dim)
```

하지만 이는 PPO의 objective와는 확실히 다르다. GRPO 가 나오기전에 구현된 코드들임에도 불구하고 위와 같이 구현했던 이유는 pretraining stage에서 context length로 나눠줬던 것이 numerical stability를 높혔기 때문이다. 하지만 RL 에서는 bias를 발생시킨다.

## Dr.GRPO: Group Relative Policy Optimization Done Right
위에서 말한 문제들을 해결하기 위해 GRPO objective에서 두 term을 모두 제거하고 `masked_mean` 을 다시 구현한다. 아래와 같이 상수 값으로 나눠준다.

```python
def masked_mean(tensor, mask, dim):
  return (tensor*mask).sum(axis=-1) / MAX_TOKENS
```

![](/assets/img/Dr.GRPO/result.webp)

- reward는 늘어나지 않는데 output length만 길어지는 현상 해결
- Incorrect response의 길이가 줄어든 것으로 보아 overthinking 이슈를 해결

## Insights
Qwen2.5 math base 모델에는 template을 사용했을 때 오히려 accuracy가 감소 이후 RL 이 다시 재구성. 따라서 pure RL이 엄청난 능력 향상을 만들었자는 주장은 과대평가일 수 있다. Base 모델과 template이 매칭이 안 맞는 경우 RL-tuning에서 성능 향상이 발생한다. 하지만 그렇지 않은 경우 (매칭이 맞는 경우) 작은 training dataset 만으로도 비슷한 성능 향상을 확인할 수 있다. 이는 새로운 지식을 넣는 것이 아닌 reasoning 능력 강화만으로 성능 향상이 가능함을 알려준다.

또 base 모델이 강하면 강할수록 RL로 얻을 수 있는 성능 효과가 크다는 것 또한 확인할 수 있었다.
