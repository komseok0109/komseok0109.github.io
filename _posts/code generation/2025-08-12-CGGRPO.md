## Measuring Code Quality in RL pipeline
Pylint, Radon, MyPy 등의 code quality analyzer 를 종합해서 code quality를 측정한다. 아래의 요소들을 이용한다.

![](/assets/img/CGGRPO/code%20quality.webp)

위의 heuristic을 이용해 `codequal_analyzer` 라이브러리를 생성해서 maintainablity, security, performance, reliability 등의 지표를 paralle 하게 측정한다. issue 의 심각도에 따라 $S=\{\text{info,low,medium,high,critical}\}$ 로 나누고 numerical score 를 assign 한다: $w_s\in\{0.5, 1.0,2.5,5.0,10.0\}$. 각 심각도의 해당하는 issue를 찾은 개수를 $N_s$ 라고 할때 최종 점수는 $W=\sum_{s\in\mathcal{S}}w_sN_s$ 이다. score를 0 과 1사이의 값으로 잡기 위해 아래와 같이 계산한다.

$$
r_{quality}=\frac{1}{1+W}
$$

Correctness Score, Format Score, 그리고 위의 quality score를 종합하여 reward를 계산한다:

$$
r_i=\frac{2}{10}r_{i,format}+\frac{3}{10}r_{i,correct}+\frac{5}{10}r_{i,quality}
$$

Format rewrad는 Python markdown code block에 코드를 넣어서 생성했고, 하나의 code block 만 답에 포함된 경우 점수를 제공한다. Correctness reward는 pass rate을 이용한다.
